# Golden Set — თარგმანის ხარისხის რეგრესიის ტესტი

ფიქსირებული საჯარო დომენის ინგლისური ნაწყვეტები, რომლებზეც პრომპტის ან
pipeline-ის ყოველი ცვლილება უნდა გატესტდეს, სანამ production-ში წავა.

## რას ფარავს თითო ნიმუში

| ფაილი | რას ამოწმებს |
|---|---|
| `01-moby-dick.txt` | გრძელი, რთული წინადადებები; თხრობის სტილის შენარჩუნება |
| `02-pride-and-prejudice.txt` | დიალოგი, პუნქტუაცია, მიმართვის ფორმები (Mr./Mrs.) |
| `03-study-in-scarlet.txt` | რიცხვები (1878), საკუთარი სახელები, გეოგრაფიული ტერმინები |

## გაშვება

```bash
pnpm quality:golden
```

მოითხოვს `ANTHROPIC_API_KEY`-ს; judge-ის ქულებისთვის `GEMINI_API_KEY`-საც.
შედეგი ინახება `results/<timestamp>.json`-ში — ორი გაშვების შედარებით ჩანს,
ცვლილებამ გააუმჯობესა თუ გააუარესა თარგმანი.

`results/` არ კომიტდება (`.gitignore`).
