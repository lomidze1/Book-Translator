# Phase Checker — ფაზის პროგრესის შემოწმება

ROADMAP.md-ის მიხედვით შეამოწმე რა დარჩა მიმდინარე ფაზაში.

## გამოყენება
```
/phase-checker
```
ან კონკრეტული ფაზისთვის:
```
/phase-checker 2
```

## რას აკეთებს:

1. წაიკითხე `docs/ROADMAP.md`
2. $ARGUMENTS ცარიელია → იპოვე პირველი ფაზა სადაც `[ ]` (unchecked) tasks არის
3. $ARGUMENTS ნომერია → კონკრეტული ფაზა
4. ყოველი task-ისთვის შეამოწმე:
   - ფაილი/module არსებობს? → `[x]`
   - ტესტი არსებობს? → note
   - კოდი სრულია? → review

## შედეგის ფორმატი:

```
## 📊 ფაზა X: [სახელი] — პროგრესი

### ✅ დასრულებული (Y/Z)
- [x] Task 1 — ფაილი: src/auth/auth.service.ts, ტესტი: ✅
- [x] Task 2 — ფაილი: docker-compose.yml

### ⏳ მიმდინარე
- [~] Task 3 — 60% (placeholder კოდი, საჭიროა real implementation)

### ❌ დაუწყებელი
- [ ] Task 4
- [ ] Task 5

### 📈 ფაზის პროგრესი: X% (Y/Z tasks)
### 🎯 შემდეგი ნაბიჯი: [რა უნდა გაკეთდეს]
```
