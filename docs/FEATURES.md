# Book Translator — ფუნქციონალის დეტალური აღწერა

## 1. ავტორიზაცია და მომხმარებლის მართვა

### 1.1 რეგისტრაცია
- **Email + პაროლი** — კლასიკური რეგისტრაცია email-ის დადასტურებით
- **Google OAuth** — ერთი დაკლიკებით რეგისტრაცია Google-ის ანგარიშით
- **ტელეფონი + OTP** — SMS კოდით რეგისტრაცია (ქართული ნომრები +995)

### 1.2 ავტორიზაცია (Login)
- იგივე სამი მეთოდი
- JWT Access Token (მოკლე ვადა: 15 წუთი) + Refresh Token (გრძელი ვადა: 30 დღე)
- "დამიმახსოვრე" ოფცია

### 1.3 მომხმარებლის პროფილი
- სახელი, ფოტო, email
- პაროლის შეცვლა
- ტელეფონის ნომრის დამატება/შეცვლა
- ანგარიშის წაშლა (GDPR-ის სტილით)

### 1.4 პაროლის აღდგენა
- Email-ით "Forgot Password" ფუნქცია
- ლინკი პაროლის აღსადგენად (1 საათი ვადა)
- Token SHA-256 hash-ით ინახება DB-ში (უსაფრთხოება)
- Rate limiting: 3 მოთხოვნა / 15 წუთი / email
- Email არსებობის არ-გამჟღავნება (ყოველთვის success პასუხი)
- **Email სერვისი:** Resend (მომავალში → AWS SES მიგრაცია)
- დეტალური იმპლემენტაციის გეგმა: [`docs/PASSWORD-RESET.md`](./PASSWORD-RESET.md)

### 1.5 Email ვერიფიკაცია (რეგისტრაციის დადასტურება)
- რეგისტრაციის შემდეგ verification email იგზავნება
- ლინკი email-ის დასადასტურებლად (24 საათი ვადა)
- ვერიფიკაციის გარეშე ზოგიერთი ფუნქცია შეზღუდულია
- "ხელახლა გაგზავნა" ოფცია

## 2. წიგნების ძებნა

### 2.1 ძებნის ინტერფეისი
- საძიებო ველი (search input) მთავარ გვერდზე
- რეალ-ტაიმ ავტო-შევსება (autocomplete / debounced search)
- ფილტრები: ავტორი, კატეგორია, ენა

### 2.2 ძებნის წყაროები
- **Google Books API** — ყდა, ავტორი, აღწერა, ISBN, ბმულები შესაძენად
- **Open Library API** — უფასო მეტადატა, დამატებითი ინფო
- **შიდა ბაზა** — ჩვენს ბაზაში არსებული წიგნების შემოწმება

### 2.3 ძებნის შედეგები
- წიგნის ყდა (thumbnail)
- სახელი, ავტორი
- მოკლე აღწერა
- რეიტინგი (თუ ხელმისაწვდომია)
- ბმულები: Amazon, Google Play Books, სხვა
- **ჩვენს ბაზაში არის?** — ბეჯი/შეტყობინება:
  - "ინგლისური ვერსია ხელმისაწვდომია — 1$"
  - "ქართული თარგმანი ხელმისაწვდომია — 5₾"

## 3. წიგნის ატვირთვა

### 3.1 ფაილის ატვირთვა
- Drag & Drop ზონა + ფაილის არჩევის ღილაკი
- მხარდაჭერილი ფორმატები: **PDF**, **EPUB**, **TXT**, **DOCX**
- მაქსიმალური ზომა: **50 MB**
- ფაილის ვალიდაცია: ტიპი, ზომა, შიგთავსის შემოწმება
- პროგრეს ბარი ატვირთვისას

### 3.2 წიგნის მეტადატა
- ავტომატური ამოცნობა ფაილიდან (სახელი, ავტორი)
- მომხმარებელს შეუძლია რედაქტირება
- ენის ავტომატური ამოცნობა (ინგლისური თუ არა)

### 3.3 დუბლიკატის შემოწმება
- ატვირთვისას ფაილის hash-ის შემოწმება
- თუ იგივე წიგნი უკვე ბაზაშია → შეთავაზება: "ეს წიგნი უკვე ნათარგმნია, გინდა 5₾-ად?"

## 4. თარგმნის პროცესი

### 4.1 თარგმნის დაწყება
- "გადათარგმნე" ღილაკი ატვირთვის შემდეგ
- პირველ რიგში → გადახდის ფორმა (10₾)
- გადახდის წარმატების შემდეგ → თარგმნა იწყება

### 4.2 AI თარგმნის ლოგიკა
- წიგნი იყოფა **თავებად/სექციებად** (არა ცალკეულ წინადადებებად — კონტექსტის შენარჩუნებისთვის)
- **Claude API** (claude-sonnet-4-6) — ძირითადი მთარგმნელი
  - დიდი კონტექსტის ფანჯარა (200K tokens)
  - კონტექსტუალური თარგმანი — ესმის ნარატივი, პერსონაჟები, სტილი
  - სპეციალური system prompt ქართული ლიტერატურული თარგმანისთვის
- თითოეული თავის თარგმნის შემდეგ შედეგი მყისიერად ხელმისაწვდომია

### 4.3 თარგმანის ხარისხის უზრუნველყოფა
- **System Prompt სტრატეგია:**
  - წიგნის ჟანრის იდენტიფიცირება (მხატვრული, ტექნიკური, აკადემიური)
  - შესაბამისი თარგმანის სტილი (ლიტერატურული vs. ტექნიკური)
  - წინა თავების კონტექსტის შენარჩუნება
  - პერსონაჟების სახელების თანმიმდევრულობა
- **Post-processing:**
  - ქართული ტიპოგრაფიის წესების დაცვა
  - ფორმატირების შენარჩუნება (თავები, აბზაცები, ნომრაცია)

### 4.4 პროგრესის ჩვენება
- რეალ-ტაიმ პროგრეს ბარი (WebSocket/Socket.io)
- "თავი X / Y მთარგმნელობს..." სტატუსი
- სავარაუდო დარჩენილი დრო
- მომხმარებელს შეუძლია დახუროს გვერდი — თარგმნა გაგრძელდება ფონში
- Push ნოტიფიკაცია / Email როცა დასრულდება

### 4.5 თარგმანის რედაქტირება
- მომხმარებელს შეუძლია ნათარგმნი ტექსტის რედაქტირება
- ცვლილებები ინახება ავტომატურად
- ორიგინალი ტექსტის ნახვა გვერდიგვერდ (split view)

## 5. Online Reader

### 5.1 კითხვის ინტერფეისი
- სუფთა, მინიმალისტური დიზაინი
- გვერდებად ან სქროლით კითხვა (მომხმარებლის არჩევანი)
- სრულ ეკრანზე რეჟიმი

### 5.2 კასტომიზაცია
- **შრიფტის ზომა** — მცირე, საშუალო, დიდი, ძალიან დიდი
- **შრიფტის ტიპი** — Serif (FiraGO), Sans-serif, ქართული შრიფტები
- **თემები:**
  - ღია (თეთრი ფონი)
  - სეპია (მოყავისფრო — თვალის დასვენება)
  - მუქი (ღამის რეჟიმი)
- **ხაზთაშორისის ინტერვალი** — 1x, 1.5x, 2x

### 5.3 სანიშნეები (Bookmarks)
- ერთი დაკლიკებით სანიშნის დამატება
- სანიშნეების სია სწრაფი ნავიგაციისთვის
- ავტომატურ სანიშნე — სადაც გააჩერა, იქიდან გააგრძელოს

### 5.4 ხაზგასმები და შენიშვნები
- ტექსტის მონიშვნა სხვადასხვა ფერით (ყვითელი, მწვანე, ლურჯი, წითელი)
- შენიშვნის დამატება მონიშნულ ტექსტთან
- ყველა ხაზგასმის/შენიშვნის ნახვა ერთ ადგილას

### 5.5 პროგრესის ტრეკინგი
- პროცენტული პროგრესი (&quot;45% წაკითხულია&quot;)
- სავარაუდო დარჩენილი დრო
- თავების ნავიგაცია (სარჩევი)
- სინქრონიზაცია ვებსა და მობილურ აპს შორის

## 6. ხმოვანი წაკითხვა (Voice Reader / TTS Service)

პლატფორმის ერთ-ერთი მთავარი ფუნქცია — წიგნის ხმოვანი წაკითხვა. TTS მოდული (`apps/api/src/tts/`) BullMQ processor-ით ტექსტს გარდაქმნის მაღალხარისხიან აუდიოდ.

### 6.1 აუდიო გენერაცია
- **თავის გენერაცია** — მომხმარებელი ირჩევს თავს და აუდიო გენერირდება
- **მთლიანი წიგნის გენერაცია** — სურვილისამებრ შეუძლია მთლიანი წიგნის აუდიოდ გარდაქმნა
- **ჰიბრიდული მიდგომა:**
  - მიმდინარე თავი — რეალ-ტაიმ streaming (სწრაფი დაწყება)
  - შემდეგი თავები — ფონში გენერირდება (უკეთესი ხარისხი)
- **პროგრესის ჩვენება** — რეალ-ტაიმში რამდენი თავის აუდიო არის მზად

### 6.2 ხმის პარამეტრები
- **ხმის არჩევა** — მამაკაცის / ქალის ხმა
- **სიჩქარის რეგულირება** — 0.5x, 0.75x, 1x, 1.25x, 1.5x, 2x
- **ხმის ტონი** — ნორმალური, ღრმა, მაღალი
- **ენა** — ქართული TTS (ძირითადი), ინგლისური (ორიგინალისთვის)

### 6.3 პლეიერის ინტერფეისი (ვები + მობილური)
- **Play / Pause / Stop** ღილაკები
- **წინ/უკან გადახტომა** — 10 წამით / 30 წამით
- **პროგრეს ბარი** — drag-ით ნავიგაცია აუდიოში
- **თავის არჩევა** — სარჩევიდან სხვა თავზე გადასვლა
- **Sleep Timer** — 15 წთ, 30 წთ, 1 სთ, თავის ბოლო
- **მიმდინარე ტექსტის highlight** — ტექსტში ხაზი გაესმება წაკითხულ ადგილს (karaoke-style sync)

### 6.4 მობილური სპეციფიკური ფუნქციები
- **Background Playback** — აპის დახურვისას/ჩაკეცვისასაც უკრავს
- **Lock Screen Controls** — ეკრანის ჩაკეტვისას Play/Pause/Skip
- **Bluetooth / AirPods მხარდაჭერა** — ყურსასმენებთან ინტეგრაცია
- **CarPlay / Android Auto** — მანქანაში მოსმენა
- **Offline აუდიო** — თავების წინასწარ ჩამოტვირთვა Wi-Fi-ზე
- **ავტომატური ჩამოტვირთვა** — შემდეგი 2-3 თავის ფონში ჩამოტვირთვა

### 6.5 აუდიო ფაილების მართვა
- აუდიო ინახება **AWS S3**-ზე MP3/M4A ფორმატში
- **Streaming** — არ საჭიროებს მთლიანი ფაილის ჩამოტვირთვას
- **Caching** — ერთხელ გენერირებული აუდიო მეორედ არ გენერირდება
- თუ იგივე წიგნი სხვა მომხმარებელმა მოითხოვა — **იგივე აუდიო გამოიყენება** (cost savings)
- აუდიო ფაილების **მოცულობის მართვა** — ძველი/არაპოპულარული აუდიოს წაშლა S3-დან

### 6.6 TTS სერვისის ვარიანტები (პრიორიტეტის მიხედვით)

| სერვისი | ხარისხი | ქართულის მხარდაჭერა | ფასი |
|---|---|---|---|
| **Google Cloud TTS** | მაღალი (WaveNet/Neural2) | დიახ, ქართული ხმები | ~$4/1M სიმბოლო |
| **ElevenLabs** | ძალიან მაღალი (ბუნებრივი) | შეზღუდული | ~$5/1M სიმბოლო |
| **Azure Cognitive Services** | მაღალი | დიახ | ~$4/1M სიმბოლო |
| **Open-source (Coqui TTS)** | საშუალო | ქართული მოდელის ტრენინგი საჭირო | უფასო |

**რეკომენდაცია:** Google Cloud TTS (Neural2) — საუკეთესო ქართული ენის მხარდაჭერა + ხარისხი/ფასის თანაფარდობა.

## 9. ნოტიფიკაციების სისტემა

### 9.1 Email ნოტიფიკაციები
- **რეგისტრაციის დადასტურება** — verification link (24 საათი)
- **პაროლის აღდგენა** — reset link (1 საათი)
- **თარგმანი დასრულდა** — CTA ღილაკი "წაკითხვა" + წიგნის სახელი (KA/EN)
- **გადახდის ქვითარი** — თანხა, წიგნი, თარიღი, ტრანზაქციის ID (KA/EN)
- **აუდიო მზადაა** — CTA ღილაკი "მოსმენა" + ხანგრძლივობა (KA/EN)
- ენა: მომხმარებლის `locale`-ის მიხედვით (ქართული ან ინგლისური)

### 9.2 Web Push ნოტიფიკაციები
- **VAPID** პროტოკოლით (W3C სტანდარტი, უფასო)
- ბრაუზერის permission request flow
- მრავალი მოწყობილობის მხარდაჭერა (PushSubscription per device)
- Notification click → ნავიგაცია შესაბამის გვერდზე
- ავტომატური expired subscription-ების გაწმენდა (HTTP 410)

### 9.3 In-App ნოტიფიკაციები
- **NotificationBell** — Navbar-ში bell icon წაუკითხავი counter badge-ით
- **NotificationCenter** — dropdown სია: სათაური, ტექსტი, დრო, წაკითხული/წაუკითხავი
- **Toast** — ახალი შეტყობინებისას bottom-right popup (5 წამი auto-dismiss)
- **Real-time** — Socket.IO WebSocket (`/notifications` namespace)
- "ყველას წაკითხულად მონიშვნა" ფუნქცია
- რელატიური დრო: "ახლახანს", "5 წუთის წინ", "2 საათის წინ"

### 9.4 ნოტიფიკაციის პრეფერენსები
- **არხების კონტროლი** — Email / Push / In-App ცალ-ცალკე ჩართვა/გამორთვა
- **მოვლენების კონტროლი** — თარგმანი / აუდიო / გადახდა ცალ-ცალკე
- Settings გვერდზე API-backed toggles (სერვერზე ინახება, არა localStorage)
- Backend processor-ები ამოწმებენ პრეფერენსებს გაგზავნამდე

### 9.5 არქიტექტურა
- **NotificationService.notify()** — ერთი entry point ყველა trigger-ისთვის
- **BullMQ queue** — email/push async, არ ანელებს translation/payment/TTS flow-ს
- **WebSocket gateway** — `/notifications` namespace, JWT auth, user-based rooms
- **Trigger points:** TranslationProcessor, PaymentService, TtsProcessor
