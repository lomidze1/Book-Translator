## 3. კროს-პლატფორმული კონტრაქტი (ყველაზე მთავარი ნაწილი)

ჰაილაითები საერთო ცხრილითა და endpoint-ებით იზიარება ვებსა და მობილურს შორის,
ამიტომ მობილურმა **იგივე კოორდინატთა სივრცე** უნდა გამოიყენოს — თორემ ერთ
მოწყობილობაზე გაკეთებული ჰაილაითი მეორეზე არასწორ ადგილას დაჯდება ან გაქრება.

ვების ლოგიკა — `apps/web/src/app/[locale]/books/[id]/read/ReaderView.tsx:146-163`
(`resolvedHighlights`):

```ts
let { startPosition: start, endPosition: end } = hl;
if (chapterText.slice(start, end) !== hl.selectedText) {
  const idx = chapterText.indexOf(hl.selectedText);
  if (idx === -1) continue;          // ვერ მოიძებნა -> ჩუმად ვარდება
  start = idx; end = idx + hl.selectedText.length;
}
```

**ინვარიანტი:**
`startPosition`/`endPosition` არის სიმბოლოს ოფსეტები ამ თავის `translatedContent`
სტრიქონში ისე, რომ:

```
translatedContent.slice(startPosition, endPosition) === selectedText
```

მობილურმა ზუსტად ამის დამაკმაყოფილებელი ოფსეტები უნდა აწარმოოს.

ვების საკუთარი ოფსეტების გამოთვლა სანახავია როგორც ეტალონი (იმავე ფაილში):
`textOffsetWithin` (~68), `handleMouseUp` (~262), `handleHighlight` (~397).

## 8. შესრულება (2026-07-27)

### რა გაკეთდა

**რატომ `TextInput`, და არა `<Text selectable>`:** RN-ს `<Text>`-ზე მონიშვნის
დიაპაზონის წამკითხავი API საერთოდ არ აქვს — `onSelectionChange` მხოლოდ
`TextInput`-ს აქვს. ამიტომ თავის ტექსტი იხატება წაუკითხავ `TextInput`-ად.
Android-ზე `editable={false}` თვითონ view-ს თიშავს
(`ReactTextInputManager` → `isEnabled = editable`), გამორთული `EditText` კი
საერთოდ არ მოინიშნება — იქ input რჩება editable, კლავიატურა კი ჩახშობილია.

**თავი = ერთი `TextInput`, არა აბზაცები:** ასე პლატფორმის დაბრუნებული
ოფსეტები **უკვე** `translatedContent`-ის ოფსეტებია (ე.ი. §3-ის ხაფანგი საერთოდ
არ ჩნდება), მონიშვნა აბზაცებს შორისაც გადადის ისე, როგორც ვებზე, და native
view-ების რაოდენობა იგივე რჩება, რაც აქამდე იყო.

- `packages/reader/src/utils/highlight-text.ts` — სუფთა, პლატფორმისგან
  დამოუკიდებელი ლოგიკა: `selectionToChapterRange`, `resolveHighlightRanges`,
  `segmentChapterText`. ინვარიანტი დაცულია კონსტრუქციით — `selectedText`
  ყოველთვის თვითონ `translatedContent`-იდან იჭრება.

  შეცვლა, წაშლა); მოდალის ყალბი „quick add" შეცვლილია მინიშნებით.
