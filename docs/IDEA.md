# Book Translator — პროექტის კონცეფცია

## ხედვა

**Book Translator** არის პლატფორმა, რომელიც საშუალებას აძლევს ქართველ მომხმარებლებს ინგლისურენოვანი წიგნები გადათარგმნონ ქართულ ენაზე ხელოვნური ინტელექტის (AI) გამოყენებით, წაიკითხონ ჩაშენებულ ონლაინ რიდერში და მოუსმინონ ხმოვანი წაკითხვით (Text-to-Speech).

## პრობლემა

- ქართულ ენაზე ხელმისაწვდომი წიგნების რაოდენობა მცირეა
- პროფესიონალური თარგმანი ძვირი და შრომატევადია
- ხელმისაწვდომი თარგმანის ხელსაწყოები არ არის ოპტიმიზებული წიგნების თარგმნისთვის — კარგავენ კონტექსტს, სტილს და ნიუანსებს

## გადაწყვეტა

ერთიანი პლატფორმა, სადაც მომხმარებელი:

1. **ეძებს წიგნს** — შეიყვანს სახელს, პლატფორმა აჩვენებს ინფორმაციას და ბმულებს სადაც შეიძლება შეიძინოს
2. **ატვირთავს წიგნს** — PDF, EPUB ან TXT/DOCX ფორმატში
3. **იხდის თარგმანის საფასურს** — ერთჯერადი გადახდა (10₾ თითო წიგნზე)
4. **AI თარგმნის წიგნს** — რეალ-ტაიმში პროგრესის ჩვენებით
5. **კითხულობს ონლაინ რიდერში** — ვებიდან ან მობილური აპლიკაციიდან
6. **უსმენს ხმოვანი წაკითხვით** — TTS სერვისი წაუკითხავს წიგნს ქართულად

## სამიზნე აუდიტორია

- ქართველი მკითხველები, რომლებსაც სურთ ინგლისურენოვანი წიგნების ქართულად წაკითხვა
- სტუდენტები, რომლებსაც სჭირდებათ აკადემიური ლიტერატურის ქართულად გაგება
- ადამიანები, რომლებსაც ინგლისური ენის ბარიერი აქვთ

## ბიზნეს მოდელი

### ფასები

| მომსახურება | ფასი |
|---|---|
| წიგნის თარგმნა (ახალი) | **10₾** |
| ბაზაში არსებული ინგლისური წიგნის შეძენა | **1$ (~2.7₾)** |
| ბაზაში უკვე ნათარგმნი წიგნის შეძენა | **5₾** (ხელახლა თარგმნა არ ხდება) |

### გადახდის მეთოდი
- **ერთჯერადი გადახდა** ყოველ წიგნზე (არა subscription)
- საქართველოს ბანკი (BOG Pay / iPay)
- თიბისი ბანკი (TBC Pay)
- კარტის მიბმა **არ** არის საჭირო

## ძირითადი ფუნქციონალი

### 1. წიგნების ძებნა
- მომხმარებელი შეიყვანს წიგნის სახელს
- პლატფორმა ეძებს Google Books API-სა და Open Library API-ში
- აჩვენებს წიგნის ინფორმაციას: ყდა, ავტორი, აღწერა
- აჩვენებს ბმულებს სადაც შეიძლება წიგნის შეძენა
- თუ წიგნი უკვე ბაზაშია — შესთავაზებს ფასდაკლებულ ვარიანტს

### 2. წიგნის ატვირთვა და თარგმნა
- მხარდაჭერილი ფორმატები: **PDF**, **EPUB**, **TXT/DOCX**
- AI-ზე დაფუძნებული კონტექსტუალური თარგმანი (Claude API)
- რეალ-ტაიმში თარგმნის პროგრესის ჩვენება
- მომხმარებელს შეუძლია ნათარგმნი ტექსტის რედაქტირება

### 3. Online Reader
- შრიფტის ზომა, ფონტი, თემა (მუქი/ღამე რეჟიმი)
- სანიშნეები (bookmarks) — სადაც გააჩერა, შემდეგ იქიდან გააგრძელოს
- ხაზგასმები და შენიშვნები

### 4. ხმოვანი წაკითხვა (Voice Reader / TTS Service)
- **ცალკე მიკროსერვისი** (`apps/tts-worker`) — მე-5 სერვისი მონორეპოში
- Google Cloud TTS (Neural2) — მაღალი ხარისხის ქართული ხმა
- თავ-თავად აუდიოს გენერაცია — ჰიბრიდული მიდგომა (რეალ-ტაიმ + წინასწარი გენერაცია)
- აუდიო პლეერი ვებსა და მობილურში:
  - Play/Pause, გადახვევა, სიჩქარის რეგულირება
  - Sleep timer, კარაოკე-სტილის ტექსტის სინქრონიზაცია
- მობილურში: ფონური დაკვრა, lock screen კონტროლები, Bluetooth, CarPlay/Android Auto, ოფლაინ ჩამოტვირთვა
- აუდიო ფაილების შენახვა AWS S3-ში, streaming და caching

### 5. მომხმარებლის პანელი (User Panel)
- ანგარიშის მართვა
- ატვირთული და ნათარგმნი წიგნების ბიბლიოთეკა
- თარგმნის ისტორია და სტატუსი
- გადახდების ისტორია

### 6. ავტორიზაცია
- Email + პაროლი
- Google OAuth
- ტელეფონის ნომერი + OTP (SMS კოდი)

## მომავლის გეგმა

- სხვა ენების დამატება (EN → KA-ს გარდა)
- ადმინისტრატორის პანელი (მომხმარებლების მართვა, სტატისტიკა, ფინანსური ანალიტიკა)
- წიგნების რეკომენდაციის სისტემა
- კომუნიტი ფუნქციები (შეფასებები, რეცენზიები)
